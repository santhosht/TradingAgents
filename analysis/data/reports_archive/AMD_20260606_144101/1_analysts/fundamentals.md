# Fundamentals Analysis Report — AMD — AMD_20260606_144101

## Valuation

AMD's valuation profile is the most important fundamental lens right now given the -10.86% drop:

- **P/E (TTM) = 156.5×** — Extremely elevated. EPS TTM = $2.98 on a $466 stock = 156× earnings. This is a "priced for perfection" multiple that assumes sustained hypergrowth.
- **Forward P/E = 35.67×** — This is where the story changes dramatically. Forward EPS = $13.08, implying the market is pricing in a ~4.4× earnings inflection from TTM ($2.98) to forward ($13.08). If AMD delivers $13+ EPS, a 35.7× forward P/E is *reasonable* for a high-growth semiconductor leader — not cheap, but not absurd.
- **PEG Ratio = 1.12** — Below 1.5 is generally considered fair value for a growth stock. PEG of 1.12 suggests AMD is priced in line with its growth rate when using forward estimates.
- **Price/Book = 11.79×** — Elevated, but book value ($39.55) is heavily depressed by the massive goodwill/intangibles from the Xilinx acquisition ($41.5B). Tangible Book Value per share ≈ $14.07. Price/Tangible Book ≈ 33× — very high.
- **EV/EBITDA = 101.2×** — Exceptionally high. Only justifiable if EBITDA expands dramatically with the forward earnings inflection.

**Valuation verdict:** Current P/E (156×) is unjustifiable on trailing earnings alone. The entire bull case rests on the forward EPS inflection from $2.98 → $13.08 materializing. If it does, AMD trades at ~35× forward — palatable. If it doesn't, or if it's delayed, multiple compression is severe.

## Growth — The EPS Inflection

The forward EPS estimate of $13.08 vs TTM EPS of $2.98 represents a **4.4× earnings inflection**. Annualizing Q1'26's $0.84 EPS gives ~$3.36 — still far from $13.08/year. Reaching $13.08 annualized requires ~$3.27/quarter EPS — a 4× step-up from current $0.84. This embeds very aggressive assumptions about AI GPU ramp (MI400 series), datacenter software monetization, and operating leverage.
